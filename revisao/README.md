# Revisao de Prova

Materiais focados em revisao e treino para avaliacao.

| Arquivo | Descricao |
|---|---|
| [revisao-prova-slides.pdf](revisao-prova-slides.pdf) | PDF com os slides de revisao da prova. |
| [simulado-enade-revisao-prova.md](simulado-enade-revisao-prova.md) | Simulado com 30 questoes, gabarito e criterios para questoes abertas. |

Como estudar:

1. Passe pelo PDF para revisar os conceitos principais.
2. Resolva o simulado sem olhar o gabarito.
3. Corrija as questoes objetivas.
4. Compare suas respostas abertas com os criterios esperados.
