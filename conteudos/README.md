# Conteudos

Esta pasta reune os guias teoricos e praticos da monitoria.

| Arquivo | Quando usar |
|---|---|
| [arquitetura-camadas.md](arquitetura-camadas.md) | Para entender MVC estendido, responsabilidades por camada e fluxo de requisicao. |
| [requisitos-rnf-uml-rtm.md](requisitos-rnf-uml-rtm.md) | Para escrever RFs, RNFs verificaveis, diagramas de sequencia e matriz de rastreabilidade. |
| [modelagem-software.md](modelagem-software.md) | Para revisar diagrama de classes, diagrama de sequencia, MER, DER e modelo relacional. |
| [fluxo-requisicao-endpoints.md](fluxo-requisicao-endpoints.md) | Para documentar rotas, metodos HTTP, status e fluxo cliente-servidor. |
| [rtm.md](rtm.md) | Para montar a matriz de rastreabilidade entre requisitos, implementacao e evidencias. |

Sugestao de estudo:

1. Leia arquitetura em camadas.
2. Revise requisitos e rastreabilidade.
3. Estude modelagem de dados e UML.
4. Revise fluxo de requisicao e endpoints.
5. Finalize montando a RTM.
